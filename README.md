## 📌 Overview

The **University Event Management System** is a comprehensive enterprise web application built using **Java EE**, **Maven**, **JPA**, **JSF**, and **JSP**. It is designed to streamline the management of university-level events.

The platform enables:
- 📋 Students to register for university events.
- 👨‍🏫 Faculty/admins to manage event logistics, participants, and winners.
- 🏆 Generation of final winners and certificates.
- 📧 Email notifications for students and faculty based on activities.

## 🚀 Features

- 🔐 Role-based login system (Student / Admin / Faculty)
- 🎟️ Event registration and cancellation
- 🛠️ Admin dashboard to manage events
- 📤 Certificate generation and download (PDF)
- 📬 Email alerts for actions (registration, winner announcement)
- 🧾 Profile and activity history
- 🏆 Winner declaration with automatic notifications

---

## 🛠️ Technologies Used

- Java EE (JPA, JSF, JSP, Servlets)
- Maven (Build tool)
- MySQL (Database)
- JavaMail API (for notifications)
- **Red Hat JBoss EAP Server** (Application Server)
